# 🧳 练手项目合集（Practice Projects）

三个适合实习生 / 初学者练手的 Python 小项目，每个项目独立成目录、可单独运行。

| 项目 | 目录 | 技术栈 | 亮点 |
| --- | --- | --- | --- |
| 📝 命令行待办工具 | [`python-cli-todo/`](python-cli-todo/) | 纯 Python 标准库 | argparse 子命令 CLI、JSON 持久化、彩色输出 |
| 📊 销售数据可视化分析 | [`data-analysis-demo/`](data-analysis-demo/) | pandas + matplotlib | 数据清洗、多维统计、中文图表、文本报告 |
| 💬 迷你留言板 | [`flask-mini-board/`](flask-mini-board/) | Flask + SQLite | 路由与模板渲染、表单处理、SQLite CRUD |

## 快速开始

每个项目目录内都有独立 README 与 requirements.txt，进入对应目录即可：

```bash
cd python-cli-todo      # 零依赖，直接 python todo.py --help
cd data-analysis-demo   # pip install -r requirements.txt && python analyze.py
cd flask-mini-board     # pip install -r requirements.txt && python app.py
```
